Category: changed
Audience: operators
Breaking-Change: no
Summary: Governed publication now revalidates the exact published bytes with an explicit outcome. `PDFGovernedExecutionRevalidation` gains a serialized `state` (`complete`/`incomplete`/`error`), `reason_code`, and `reason`; byte-level failures are named (`expected-digest-missing`, `artifact-unreadable`, `artifact-digest-mismatch`, `artifact-reopen-failed`) and an empty or malformed expected digest is refused outright instead of silently skipping byte binding. `isSignOffEligible()` now requires `state == "complete"`. `revalidateGovernedArtifact`/`finalizeGovernedPublication` accept an optional `PDFGovernedRevalidationScope` (also carried on `PDFGovernedMutationRequest`): a complete, targeted impact plan runs a targeted inspection, anything undeclared/incomplete/document-wide or without a baseline falls back to a full run, and the finding delta between the baseline and the published-bytes inspection is folded — with the scope mode, reason, plan, and baseline digest — into the revalidation report, so `reportSha256` (and the sign-off) covers the delta. Surfaces report the explicit state instead of a bare `failed`: `PdfTool repair` writes `incomplete`/`error` plus `revalidation_state`/`revalidation_reason_code`, the Action List governed summary carries `status`/`reason_code`/`state`, and PageMaster manifests add `state`/`reason_code`. Inspecting an in-memory candidate or pre-publication bytes still cannot close an operation — only a finalize against the published/staged artifact can issue a sign-off. Reviewer can check `emptyOrMalformedExpectedDigestIsRefused`, `tamperedPublishedBytesFailRevalidationAndNeverSignOff`, `revalidationReportsIncompleteStateExplicitly`, `targetedMatchesFullOnPublishedBytes`, `undeclaredImpactFallsBackToFullInspection`, `inMemoryCandidateValidationCannotCompleteOperation` in `UnitTests/tst_governedexecutiontest.cpp`.
