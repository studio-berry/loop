Summary: Rollback becomes a governed publication and cross-surface parity gets a named CI fixture. `PDFOperationHistoryStore::rollbackTo` (`LoopLibCore/sources/pdfoperationhistorystore.{h,cpp}`) restores a recorded revision as a new revision and then runs the same #38 finalize path (`finalizeGovernedPublication`): it revalidates the restored bytes and issues a sign-off certificate bound to them. The `rolled-back` event now records `resultSummary.governed = { approval, revalidation, sign_off }`, the revalidation report digest, and the effective profile digest, so `scripts/ci/check_governed_parity.py` accepts a rollback receipt like any other surface. `PDFRollbackRequest` gains the effective preflight profile and a sign-off actor/policy; a rollback without them is refused (`rollback-profile-missing`). A `verify()`-before-append guard refuses to extend a compromised chain, and a revalidation failure fails closed (the restored destination is removed, a failed event is appended, no sign-off or receipt). The Editor `requestFixRollback` supplies the validated preflight profile it already holds. A new JSON-only `pdftool rollback <document> --to <sha256> --output <file> --profile <profile>` command exposes the surface headlessly with the four registration points (`describe()`, `describeOptions`, `initializeCommandLineParser`, `getOptions`) and the JSON-default lists in `main.cpp`. Cross-surface parity: `UnitTestsProductOperatorLoop::governedPublicationParityAcrossSurfaces` drives CLI repair, CLI action-list, the Editor Action List route, and a PageMaster export over one fixture and one equivalent `add-bleed` plan, asserts every receipt passes the parity checker, and asserts the shared source/effective-profile identity and the action-list plan digest. The named fixture lives in `UnitTests/testdata/governed-parity/` (regenerated with `LOOP_GOVERNED_PARITY_OUT`), the governed-execution proof lane now binds `UnitTestsProductOperatorLoop`, and the `architecture/invariants.yaml` D5 TODO is closed by a `source_integrity` CI step that runs `check_governed_parity.py` over the committed receipts. Docs updated: `docs/OPERATION_HISTORY.md`, `docs/GOVERNED_EXECUTION.md`, `docs/PDFTOOL_CLI_CONTRACT.md`. Action List and PageMaster rollback surfaces are deferred (recorded). Reviewer can check `rollbackRevalidatesAndRecordsGovernedReceipt`, `rollbackRefusesWithoutProfileOrOnCompromisedChain`, `rollbackPointsRetentionAndAtomicity` (`UnitTests/tst_operationhistorytest.cpp`), `rollbackRestoresRecordedRevisionWithGovernedReceipt`, `rollbackAdvertisesJsonOnlyGovernedSurface`, `rollbackRejectsNonJsonOutput` (`UnitTests/tst_pdftoolcontract.cpp`), and `governedPublicationParityAcrossSurfaces` (`UnitTests/tst_productoperatorloop.cpp`).
