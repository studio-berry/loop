# Async interactive-thread boundary (issue #144)

Category: added
Audience: developers
Breaking-Change: no
Summary: Add `pdf::PDFBlockingThreadGuard`, a runtime thread-affinity check a blocking service adapter opens with so it refuses to run on the registered interactive (canvas) thread instead of stalling pointer and frame handling; wire it into `PreflightEngine::run()` and register `EditorHost`'s owning thread as the interactive thread. Add `PDFJobKind` to `PDFJobTraceEvent` so job traces identify async work by type. Document the UI-thread boundary in docs/JOB_SCHEDULER.md.
