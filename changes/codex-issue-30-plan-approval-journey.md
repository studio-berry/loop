Summary: Add an end-to-end acceptance fixture for the plan and approval journey. It proves that an unapproved plan, a plan the operator rejected, a plan whose document revision has moved, and a plan replanned after approval can each neither execute nor publish anything; that a run needs an approval given for the plan displayed at that moment; and that completion presents the revalidated verdict together with the 64-hex digest of the artifact it published, distinct from the as-received input. The digest-equality clause inside fixLifecycleStateName() and the fixPlanIsCurrent() clause in approveActionListPlan() are second lines of defence against a state this journey offers no path to, so the fixture pins the reachable enforcement, which is that accepting a plan clears the review. Mutation-probed by removing each guard in turn: the execution arming check, the revision comparison, the superseded predicate and the review clearing each make the fixture fail.
