Audience: operators

Summary: One cancellation-safe entry point now owns approved corrective publication. `pdf::executeGovernedMutation()` in `pdfgovernedexecution.{h,cpp}` validates the approval identity and authorization (#36), refuses an already-terminal replay (`already-terminal`; one plan produces one published candidate), checks cancellation, stages the reviewed bytes beside the destination, finalizes against the staged bytes (reopen + revalidate + sign-off), runs the `beforeCommit` seam and a second cancel check, commits atomically through `PDFSafeFileWriter`, reads back, and returns a terminal `PDFGovernedMutationReceipt` (schema `loop.governed-mutation-receipt`). Any refusal, failure, or cancellation before the commit leaves no destination artifact — this closes the write-then-finalize hole on every surface; a failure after the commit is terminal `failed` with the artifact present and the reason recorded. PdfTool `repair`, PdfTool `action-list run|batch`, PageMaster exports, and the Editor Action List worker all route their publication through the gateway; PageMaster keeps its `beforeOutputCommit` seam wired to the gateway's `beforeCommit`, and the Editor worker now validates the exact staged bytes it applies rather than a second serialization. `EditorHost::confirmActionListPlan()` ("Approve and run") now requires the armed/approved path, so an unreviewed plan is refused. Editor Save As / document I/O and the legacy ad-hoc repair commands stay out of the gateway (documented). Reviewer can check `gatewayRefusesMalformedRequestBeforeWrite`, `gatewayRefusesStaleApprovalBeforeWrite`, `gatewayRefusesUnauthorizedApprovalBeforeWrite`, `gatewayRefusesAlreadyTerminalReplay`, `gatewayDestinationConflictLeavesExistingFileUntouched`, `gatewayCancelAtCommitSeamLeavesDestinationUntouched`, `gatewayRevalidationFailureLeavesDestinationUntouched`, `gatewayHappyPathPublishesExactlyOnce`, `repairRefusesStaleApprovalBeforeWrite`, `governed_gatewayCancelBeforeCommitWritesNothing`, `confirmActionListPlanRefusesAnUnreviewedPlan`, and the Mutation gateway section in docs/GOVERNED_EXECUTION.md. The gateway rechecks current authorization before commit, verifies history and artifact metadata before publication, and binds replay detection to the recorded plan or execution rather than candidate bytes alone.
