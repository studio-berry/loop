Summary: Fix the systematic Windows native Quick startup crash/hang and make its smoke probe fail fast and fail closed. The global log message handler scrubs on whatever thread logs, so the render thread and main thread reached the shared static QRegularExpression matchers concurrently during scene-graph startup; scrub() now compiles those patterns exactly once via std::call_once (observed invalid-regex warning plus 0xC0000005 after scene_graph_initialized on GPU-less runners). The relocated-install smoke probe retries the native launch up to 3 times, bounds every attempt with a wall-clock timeout (Start-Process + WaitForExit, default 45 s), force-kills hung probes with a bounded post-kill poll (never a blocking WaitForExit), and falls back to the D3D11 WARP software adapter on later attempts so the reported graphics API stays genuinely d3d11; a systematic startup failure still fails every attempt and fails closed.
