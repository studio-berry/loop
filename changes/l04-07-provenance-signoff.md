Summary: Governed provenance converges on one authoritative chain with a reconstruction reader and a stale-sign-off rule. `reconstructGovernedPublicationAudit(store, publishedSha256, &audit)` (Core, `pdfoperationhistorystore.{h,cpp}`) reconstructs plan digest, the authorizing approval, execution identity, artifact digests, the #38 validation state + finding-delta summary, and the sign-off for one published output — every link read from chain events, refused (`chain-compromised`, `chain-unavailable`) when `verify()` fails and refused (`no-accepted-publication`) when no accepted event binds the exact output. `PDFOperationHistoryStore` gains an `execution(QUuid)` getter and `PDFGovernedPublicationAudit` (serialized as `loop.governed-publication-audit`). `PDFGovernedExecutionSignOff` gains `fromJson`, so a stored sign-off round-trips instead of being display-only. `verifyGovernedSignOffAgainstArtifact(signOff, publishedPath)` re-reads and re-hashes the artifact and refuses (`invalid-document-changed`) when it no longer matches `publishedSha256`; the evidence-bundle path wires it in via `PreflightEvidenceBundleRequest::publishedArtifactPath` and now refuses a sign-off supplied with neither the artifact nor an output identity instead of silently synthesizing the output identity from the sign-off. Producer identity fixes (P4): the mutation gateway's running and failed `FixApplied` events bind `effectiveProfileDigest` (previously only the accepted completion did), and the legacy `PdfTool add-bleed` accepted approval carries `evidenceSha256` + a `decisionReference` bound to the published output (a targeted fix; add-bleed convergence stays #37). `PDFOperationHistoryStore` remains the single chain (0.4.0 canon); the PageMaster manifest is documented as a reference, not authority, with its reconciliation owned by #37. No CLI entry point for the reader yet (deferred). Reviewer can check `governedPublicationAuditReconstructsAfterReopen`, `governedPublicationAuditRefusesOnTamperedChain` (`UnitTests/tst_operationhistorytest.cpp`), `governedSignOffRoundTripsAndRejectsStaleArtifact`, `gatewayEventsBindCompleteIdentities` (`UnitTests/tst_governedexecutiontest.cpp`), `evidenceBundle_rejectsStaleSignOff` (`UnitTests/tst_preflightverdicttest.cpp`), `repairPublicationBindsCompleteEventIdentities` (`UnitTests/tst_pdftoolcontract.cpp`), and the Action List history assertions in `cliParityRecipeHashAndOutputSha256` (`UnitTests/tst_actionlisttest.cpp`).

Audit reconstruction excludes inspection events and refuses sign-offs that disagree with the recorded publication identities.
