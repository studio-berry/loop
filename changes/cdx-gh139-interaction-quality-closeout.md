Summary: Close out the remaining children of the interaction-quality epic (gh-139). Fix gh-145 AC5: the canvas hit tolerance was computed once in EditorHost::bindCanvas() as `2.0 / zoom` and never updated, so the only screen-space tolerance in the product went stale at the first wheel notch; HitTestDispatcher now owns a screen-pixel tolerance and converts it to page units per hit test against the live zoom, which InteractionController pushes before dispatching. PageSpatialIndex gains a rectangle query (a tolerance-expanded point can straddle a cell boundary, which the point query would miss) that de-duplicates items spanning several probed cells. Add the gh-145 snapping seam: DragSnapper, ISnapProvider and PageBoxSnapProvider in LoupeLibInteraction, applied only after the drag hysteresis threshold and only to DragSession::previewPageBounds, with an Alt suppress modifier sampled from the current intent on every move rather than latched at press; DragSession records what it snapped to so a future commit path need not re-derive it. `pdf::PDFSnapper` is deliberately not wrapped. Add gh-144's thread-affinity guard: pdf::PDFThreadAffinity marks the interactive thread in LoupeEditor/main.cpp, and preflight, OCR, file I/O, page render, font scan and image decode each open with requireNotInteractive(), turning "this blocking service was called from an input handler" from a review question into a reportable violation with a test-installable handler. Add SchedulerPreflightService, the producer PreflightController never had — its beginRun/acceptResult/cancelRun had zero product callers, so editor preflight could not be started at all; the controller's Running state is now set synchronously before submission (gh-144 AC3) and the result crosses back as a value through JobRelay. Extend InteractionTraceRecorder for gh-145 AC7 and gh-144 AC7 in one schema bump (version 2): hit-test index-candidate and precise-hit counts plus duration, collected on the pass that was going to run anyway, and per-job-kind overlap counts saying which kinds of work were in flight when a frame missed its budget; TraceJobKind mirrors pdf::PDFJobKind under static assertions. Correct docs/JOB_SCHEDULER.md, whose migration table wrongly claimed editor preflight and thumbnail generation were migrated and reported 13 QtConcurrent debt sites where the allowlist holds 1; add docs/ASYNC_BOUNDARY_DEFERRED.md registering AI/LLM, thumbnails, image decode, font scan and batch analysis with the explicit condition that turns each into real work, and document the tolerance, snapping and thread-affinity contracts in docs/INTERACTION_CONTRACT.md.
