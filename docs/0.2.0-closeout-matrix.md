## What this harvest closes vs. what it cannot

Closeable now, pending only a real CI run: Q-02 (S21 benchmark evidence) and Q-04
(Windows/Linux native + software `QuickShellSmoke`), plus the focus-bridge probe
evidence that Q-03's static checks assume will later run for real.

**Cannot be honestly closed before Phase 4 produces a shipped product Quick
module:** P-01 (clean-machine package smoke) and P-02 (final-artifact SBOM/
notices/LGPL). Both require an installed artifact to inspect; at P4-S1 there is
only a non-installed qualification harness. Treat these two as Phase-4-exit
gates the checklist miscategorized as pre-P4-S1 gates, and say so explicitly
wherever this status is reported — including in the Notion checklist update —
rather than ticking them.
