## Phase 1 acceptance

Phase 1 is complete when:

- the candidate base is refreshed from live `stable` and recorded;
- no active authority text permits Widgets or hybrid as the 0.2.0 product
  outcome;
- the Quick-only dependency, ownership, and QML security boundaries are
  explicit;
- every remaining gate has an owner and evidence path in this matrix;
- historical 0.1.1 work is labeled as 0.2.0 carry-forward rather than a
  pending release;
- no runtime, package, or release claim is promoted from this phase.
