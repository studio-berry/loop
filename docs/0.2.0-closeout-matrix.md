This matrix is the working acceptance ledger for the 0.2.0 closeout. It keeps
implementation, static, automated, integrated runtime, independent/platform,
and release evidence separate. A row cannot become `acceptance verified` from
local implementation evidence alone.

lifecycle, supply-chain, audit, and promotion gates remain open until their
own sessions prove them.
