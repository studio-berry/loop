# 0.1.2 S20b / #143 handoff

Status: implementation complete locally; hosted closure remains separate.

## Delivered

- Added an optional `IDocumentOverlayInterface` and immutable
  `PDFOverlayContext` without changing the existing draw-interface contract.
- Added a dedicated, clipped overlay pass with deterministic layer and
  registration ordering.
- Kept legacy page and post-rendering callbacks operational.
- Migrated Loupe preflight markers to the independent overlay pass and retained
  stable finding/object identifiers from the report contract.
- Added production-path tests for ordering, transforms, page switching,
  overlay-only cache preservation, invalid geometry, high marker counts, and
  overlay trace timing.

## Boundaries

This session does not reopen #89, add a neutral cross-presentation library, or
migrate every existing tool/plugin from the compatibility drawing callbacks.
The overlay interface is Widgets-internal and is intended to be adopted by
future selection, handle, guide, and tool-preview providers.
