# 0.1.2 S19a / #140 handoff

## Scope

S19a adds an opt-in interaction trace recorder to the existing QWidget canvas.
The recorder is private to `LoupeLibWidgets`, enabled only through the existing
`PDFRenderer::DisplayTimes` diagnostic flag, and reports aggregate timing data.
It does not create a public API, persisted format, Qt Quick surface, or second
diagnostics framework.

## Delivered

- [x] Bounded interaction/frame samples and stage timing.
- [x] Explicit available/unavailable timing values and evidence state.
- [x] Privacy-safe aggregate JSON output with no document payload, paths, pixels,
  event payloads, or user identifiers.
- [x] Optional developer overlay using the existing QWidget diagnostics path.
- [x] Deterministic trace recorder and privacy regression tests.
