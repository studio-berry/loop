## 0.2.0 qualification commands

Against the candidate SHA:

```text
python scripts/agent/check-change.py --base origin/dev
python scripts/generate-architecture-catalogs.py --check
QT_QPA_PLATFORM=offscreen ctest --test-dir <build> -C Release \
  -R "UnitTests(InteractionController|OverlayFrame|PageSurface|QuickCanvas|ViewportController|EditorHost)" \
  --output-on-failure
```

Windows Release qualification additionally requires deploying Qt/Loop DLLs beside
test executables before CTest; see [CI.md](../CI.md#windows-local-test-executables).
