# 0.1.2 S20a / #142 handoff

Status: production path implemented; S20a remains open pending final closure
evidence.

## Scope

This session promotes the #142 proof contract into the shipped Widgets
viewport. It does not add a neutral library, Qt Quick code, persistent
customer-content storage, or issue #54's backend partial-page renderer.

## Delivered

- `docs/S20A_PAGE_SURFACE_CONTRACT.md` defines complete key identity, request
  generations, cache budget authority, priority shedding, progressive reuse,
  and the production boundary.
- `PDFDrawWidgetProxy` now owns a private revision-fenced rendered-surface
  cache. It reuses compatible surfaces while the existing asynchronous page
  compiler produces the higher-fidelity result, uses the configured compiled
  page byte limit, and invalidates on document/profile/renderer changes.
- Rendered page content is cached separately from the existing post-render
  overlay interfaces, preserving independent overlay invalidation.
- `UnitTestsPageSurfaceProbe` exercises cache reuse, transformed surfaces,
  generation/revision fencing, byte-budget rejection, deterministic eviction,
  priority shedding, and the real `PDFDrawWidget` paint path using the
  editor-default `Blend2D_MultiThread` renderer. The production test verifies
  surface misses/hits and a revision-fenced miss after document mutation.
- The cache remains private to Widgets; no public interface or new library was
  added.

## Verification to run

Configure/build with the existing Qt/vcpkg toolchain, deploy the full Windows
dependency set beside `UnitTestsPageSurfaceProbe.exe` (including
`Qt6Gui.dll`, `lcms2-2.dll`, and `platforms/qoffscreen.dll`), then run:

```text
QT_QPA_PLATFORM=offscreen ctest --test-dir <build> -C Release -R "UnitTests(PageSurfaceProbe|InteractionState|InteractionWidget|InteractionTrace|DocumentSession|JobScheduler|Accessibility)" --output-on-failure
python scripts/agent/check-change.py --base origin/dev
```

The dependency-populated build folder remains untracked. Hosted CI and Notion
closure are separate gates. S20a is not marked complete until the focused
production evidence and the repository change verifier are green on the final
branch state. The local verifier completed all builds and focused tests, but
reported `incomplete` because `clang-format` and `clang-tidy-18` are unavailable
in this environment. The next session should rerun those checks in a toolchain
that provides them and confirm the hosted result.

Remaining implementation boundaries are intentional: the new surface cache is
used by the Blend2D production path and the existing QPainter path retains its
original compiled-page drawing fallback; near-viewport compilation remains
owned by the existing bounded one- or two-page prefetch path. Do not claim
global renderer coverage or new priority-shedding behavior from the probe alone.
