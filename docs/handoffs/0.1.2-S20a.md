# 0.1.2 S20a / #142 handoff

## Scope

This session implements the gate-aware #142 proof surface: an internal page
surface contract and a test-only Widgets probe around the existing
`PDFDrawWidgetProxy` renderer. It does not implement a shipped cache, a new
neutral library, Qt Quick code, persistent customer-content storage, or issue
#54's backend partial-page renderer.

## Delivered

- `docs/S20A_PAGE_SURFACE_CONTRACT.md` defines complete key identity, request
  generations, cache budget authority, priority shedding, progressive reuse,
  and the G2 stop rule.
- `UnitTestsPageSurfaceProbe` exercises cache reuse, transformed surfaces,
  generation/revision fencing, byte-budget rejection, deterministic eviction,
  priority shedding, and a real `PDFWidget`/`PDFDrawWidgetProxy` render.
- The probe is test-only and links the existing Widgets/Core targets; no public
  interface or new library was added.

## Acceptance evidence

| Requirement | Evidence |
| --- | --- |
| Complete revision/key identity | `PageSurfaceKey` and `RequestIdentity` in the probe |
| Request-generation supersession | stale-result test |
| Revision/cache invalidation | revision-conflict test |
| Existing byte budget remains authoritative | budget/rejection test |
| Near-viewport work sheds first | priority-shedding test |
| Progressive cached surface reuse | compatible-surface and transform test |
| Existing Widgets path exercised | `rendersThroughExistingWidgetsPath` |
| No persistent cache/new neutral target | test-only implementation and source review |

## Verification to run

Configure/build with the existing Qt/vcpkg toolchain, deploy the full Windows
dependency set beside `UnitTestsPageSurfaceProbe.exe` (including
`Qt6Gui.dll`, `lcms2-2.dll`, and `platforms/qoffscreen.dll`), then run:

```text
QT_QPA_PLATFORM=offscreen ctest --test-dir <build> -C Release -R "UnitTests(PageSurfaceProbe|InteractionState|InteractionWidget|InteractionTrace|DocumentSession|JobScheduler|Accessibility)" --output-on-failure
python scripts/agent/check-change.py --base origin/dev
```

The dependency-populated build folder remains untracked. Hosted CI and Notion
closure are separate gates; this handoff does not claim them green.
