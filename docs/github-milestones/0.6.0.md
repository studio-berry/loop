**Planned milestone.** Proposed by `docs/ROADMAP_0.5.0-0.10.0.md`; activates only after 0.5.0 release acceptance.

## Canonical name
Governed Intake — Scanned Specifications, Page-Gated OCR & Request-to-JobSpec

## Critical path
Live-text-first classification → page-gated OCR evidence → deterministic spec parsing → candidate JobSpec with source spans → operator confirmation into the job spine

## Objective
Scanned or image-only inputs and unstructured requests become structured, provenance-carrying JobSpec candidates. OCR output is evidence with producer, confidence, and source span — it never overrides live text and never changes a deterministic verdict except by producing cited evidence records. The operator confirms; the 0.5.0 spine records.

## Owns
The OCR evidence contract and Evidence Graph integration, page-gate classification, `LoupeOcrService` sidecar lifecycle and packaging, deterministic specification-field parsers (the offline fallback), candidate-JobSpec assembly, optional agent-assisted extraction through the 0.4.0 inference boundary, and the intake review surfaces.

## Out of scope
Searchable-PDF write-back, OCR-driven verdict changes, live inbox/API integrations, PageMaster batch OCR, training pipelines, handwriting recognition.

## Sequence
0.5.0 → **0.6.0** (planned) → 0.7.0 → 0.8.0 → 0.9.0 → 0.10.0
