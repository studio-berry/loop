**Living milestone.** Former planning alias: **0.0.5**. Supersedes the retired **0.1.3** GitHub milestone title.

## Canonical name
Governed Corrections, Preview, Approval & Sign-off

## Critical path
Operation registry + dry run → preview + approval + execute → recheck + sign-off + rollback

## Objective
Deliver the first complete trustworthy production correction loop:

**finding → proposed operation → dry run → preview/diff → approval → execute to new artifact → revalidate → sign off → recover/rollback if needed**

## Owns
Versioned semantic-operation registry, dry-run planning, technical and visual preview/diff, operator approval, execution to new output by default, append-only provenance, deterministic post-operation revalidation, sign-off records, and cross-surface parity (desktop, CLI, PageMaster, Action List).

## Out of scope
The agent may not gain direct mutation authority. Job intake, workflow learning, OCR, press/RIP reconciliation, and full MIS functions remain downstream. Leftover 0.2.0 operator/product/trust work belongs in **0.2.1**, not here.
