**Living milestone.** Former planning alias: **0.0.4**.

## Canonical name
Operator Experience, Interaction Architecture & Evidence Navigation

## Critical path
Host-neutral interaction architecture → measure canvas host → shell + navigation + preview

## Objective
Turn the 0.1.1 semantic substrate into a coherent, accessible, fast Loupe desktop experience for one open PDF without introducing a second source of technical truth.

Operator loop: **open → detect → pinpoint → inspect → understand state**

Correction execution is intentionally downstream in **0.1.3**.

## Entry gate
Freeze UI-facing versions of artifact/revision identity, evidence/finding identity, verdict states, profile/report compatibility, cancellation/stale-result behavior, and operation/provenance interfaces from 0.1.1.

## Notes
Qt Quick Controls is the selected shell direction. The PDF canvas architecture is **not** preselected and must be measured (ADR-backed).

## Out of scope
Production execution/approval/sign-off as a finished workflow; autonomous agent behavior; deleting approved modular tools.

**0.1.2** (current) → **0.1.3** → **0.1.4**
